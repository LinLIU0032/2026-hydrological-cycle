# 04_what_is_cycling

这一页先把"循环"这个词的含义立住。请学生看中间这句核心话：物质在地球系统的储库之间持续迁移，而不是一次性的单向流动。图上有五个储库，分别是大圈、水圈、生物圈、冰冻圈和岩石圈，它们围成一圈，中间的箭头是双向的，表示物质既能进去也能出来。讲的时候可以先问学生：水从哪里来、到哪里去，然后指出每个储库既是来源也是去向。这一页对应理解地球第八版第十二章关于气候系统组成部分的论述，以及中文教材第三、四章把水和碳称为表层系统最重要物质的说法。要点是：接下来无论讲水还是讲碳，用的都是这张"储库加箭头"的图，只是换物质、换时钟。

# 05_four_ideas

这一页给出本讲的阅读框架，四个词：储库、通量、停留时间和反馈。请学生把注意力放在四张卡片上，每张卡片先给英文术语，再给中文解释。第一个词储库，指物质被存放的位置，大小用储量衡量。第二个词通量，指物质在储库之间移动的速率，单位是质量除以时间，例如每年吉吨碳。这里要特别强调储量和通量是两回事，储量大的储库不一定交换得快。第三个词停留时间，衡量储库更新的快慢，大气水大约九天，海洋水大约三千二百年，差距极大。第四个词反馈，正反馈放大初始变化，负反馈反向作用并趋于稳定。底部那条橙色提示是关键：这四个词会在第二部分碳循环里原样复用，框架不变，只是换了物质和时钟。来源是理解地球第八版第一二零五页和第一六四七到一六五零页，以及地球画像第八百八十一页。

# 06_where_is_water

这一页要建立"地球上的水高度不均匀分布"这个直觉。左边的条形图按对数尺度绘制，因为六个储库的体积跨越了五个数量级，用线性尺度后三个会看不见。请学生从上往下读：海洋占百分之九十五点九六，体积约一点四乘以十的九次方立方千米；冰川和极地冰占百分之二点九七；地下水占百分之一点零五；湖泊河流只有百分之零点零零九；大气水百分之零点零零一；生物圈水百分之零点零零零一。右边上方那个大数字九十五点九六强调海洋占绝对多数，其余所有储库加起来只有百分之四点零四。右边下方进一步指出，冰川大多难以直接利用，真正容易利用的表层淡水极少，所以"水很多"不等于"可用的淡水很多"。所有数值只来自理解地球第八版图十七点一，中文教材图三点三只作备用，两套数据没有混用。

# 10_ocean_land_budget

这一页用理解地球第八版图十七点二的全球水量收支，训练学生把箭头方向和数值一起读。先看中间的大气带，它是小储库但交换很快。左边海洋向上蒸发四百三十四，向下降水三百九十八；右边陆地向下降水一百零七，向上蒸散七十一。中间那条橙色横向箭头是大气输送三十六，把海洋净蒸发的水送到陆地上空；底部那条橙色箭头是径流三十六，把陆地的净水送回海洋。请学生自己验算两个闭合：海洋侧四百三十四减三百九十八等于三十六，陆地侧一百零七减七十一等于三十六，两边都是三十六，说明全球收支是闭合的。所有数值单位都是一千立方千米每年。讲的时候强调方向不能搞反：蒸发向上、降水向下、输送从海到陆、径流从陆到海。中文教材图三点十五只作备用，它的面板单位没有和主图混用。

# 11_phase_changes

这一页的核心是：水的相变同时搬运水和能量，而且汽化潜热远大于熔融潜热。左边直接放中文教材图三点十七这张批准的原图，箭头方向和所有数值都原样保留，没有改动。右边三张数值卡片帮学生把图上的数字读清楚：固液之间熔融或冻结约正负八十卡；液态水在零到一百摄氏度之间加热或降温约正负一百卡，这是显热不是相变；液气之间汽化或凝结约正负五百四十卡。下面还保留教材的单位换算，一卡等于四点一八四焦。底部那条橙色提示是本页最重要的结论：气液相变的能量大约是固液相变的七倍，也就是五百四十除以八十，这个不对称正是水循环能够大量搬运能量的原因。讲的时候可以让学生比较这三个数字，体会为什么蒸发和凝结在气候里比融化和冻结更重要。

# 12_evaporation_evapotranspiration

这一页是一张原生的、可编辑的过程图，不是截图。请学生看三根向上的箭头，它们代表水返回大气的三条路径。左边是海洋表面的蒸发，中间是陆地表面和土壤的蒸发，右边是植被的蒸腾，用三棵简化的树表示。三根箭头都指向顶部的大气带，说明无论来源是海洋、陆地还是植物，水最终都以水汽形式回到大气。底部那条蓝色定义带把三个过程合并：蒸散等于蒸发加蒸腾，其中蒸发来自海洋和陆地表面，蒸腾来自植被。讲的时候可以补充中文教材第四点三点五节的说法，全球大陆蒸散把大约百分之八十到九十的水返回大气，一棵大树每天蒸腾二百到一千升水。来源还包括理解地球第八版第一六五三到一六五四页和第一一六八页，那里分别讲了蒸发和植物把地下水通过叶片返还大气的过程。

# 21_why_carbon

这一页是从水到碳的过渡，也是第二部分的启动 cue。顶部那条橙色横幅明确告诉学生：现在进入第二部分碳循环，框架不变，变的只是物质和时钟。中间的桥接图把碳放在中心，四个方向分别连接气候、生命、海洋和岩石。请学生注意箭头的颜色：气候和生命用橙色，表示碳的快速生物和大气路径；海洋用蓝色，呼应第一部分的水；岩石用棕色，表示慢地质路径。这四条连接说明碳把气候、生命、海洋和岩石用同一套储库和通量语言串了起来。底部那条框架带把第一部分学过的三个词原样搬过来：储库、通量、停留时间，告诉学生不需要重新学一套语言。来源是理解地球第八版第一二零四到一二零五页关于碳循环定义的论述，以及中文教材第四点一节把碳循环描述为氧化还原过程、生命用光合作用把无机碳转成有机碳的说法。

# 22_carbon_reservoirs

这一页有一个必须讲准确的点，请特别注意。左边放的是理解地球第八版图十二点十九这张批准的原图，它是本页唯一的数值数据集。右边的数值升序图只从这张图里取四个储库的总量，按从小到大排列：生物圈五百，大气八百三十，土壤一千五百，海洋三万八千，单位都是吉吨碳。这里要强调，最小的是生物圈五百，不是大气；大气八百三十是第二小。请千万不要把大气说成这些储库里最小的。下面那张灰色卡片是单独的一组，沉积物和岩石圈属于地质储库，图十二点十九没有印出它们的具体总量，所以这一页只作定性处理，不给它们编号，也不并入上面的数值升序，更没有引入第二套数值数据。讲的时候可以问学生：为什么海洋碳这么多，但大气碳的变化对气候影响这么直接，借此引出下一页的碳循环通量。

# 24_same_framework_different_timescales

这一页把水和碳放到同一个框架里对齐，但要点明时钟不同。左边是一张三行两列的对照表，三行是储库、通量、停留时间，两列分别是水和碳。储库这一行，水有海洋、大气、冰雪、地下水、湖泊河流和生物圈，碳有大气、生物圈、土壤、海洋、沉积物和岩石圈。通量这一行，水是蒸发、降水、径流、入渗、地下水流和蒸腾，碳是光合作用、呼吸、分解、海气交换、风化、埋藏和火山脱气。停留时间这一行只做定性比较：水的不同储库时钟差异大，大气以日计、海洋以千年计；碳则有快路径和慢路径并存，时钟跨越多个数量级。右边那个时钟对比帮学生建立直觉：水是单一物质、多个储库时钟；碳是同一物质、快慢两套时钟并存，快的来自生物和海气，慢的来自地质。底部明确写了本页只做定性对齐，不合并成统一的数值时间表。来源是理解地球第八版第一二零五到一二零六页和第一二零九到一二一三页，以及中文教材图四点十五和图四点十六。
