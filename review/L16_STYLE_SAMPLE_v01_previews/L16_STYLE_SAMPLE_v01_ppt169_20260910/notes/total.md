# 01_Lecture 16 Hydrological Cycles 第16讲 水文循环

这一讲把水循环和碳循环放在同一个地球系统框架中理解。我们会反复使用六个关键词：储库、通量、停留时间、耦合、反馈和时间尺度。重点不是记住孤立名词，而是看清物质储存在哪里、怎样转移，以及这些转移如何影响气候。

---

# 02_学习目标 Learning Objectives

完成本讲后，首先要能识别水循环的主要储库和通量，并区分储量、通量与停留时间。随后要能描述碳的主要储库，以及快速的生物和海洋路径与缓慢的地质路径。更进一步，我们要解释水和碳如何连接大气、海洋、岩石与生命，并用初始变化和诱发变化的方向区分正反馈与负反馈。最后，把方向与时间尺度结合起来，预测地球系统受到扰动后的响应。

---

# 03_目录 Table of Contents

课程分为三个连续部分。第一部分建立水循环的储库、通量、停留时间，以及地表与深部之间的联系；第二部分用同样的语言阅读快速和缓慢碳循环，并重点认识海洋碳泵。第三部分把水和碳重新耦合到同一个气候系统中，用反馈符号和响应时间判断系统变化。阅读顺序是水、碳、耦合与反馈。

# 09_全球水循环 Global Hydrologic Cycle

面对全球水循环图，先不要急着追箭头，而要先找储库，包括海洋、大气、冰雪、陆地生命和地下水。第二步才是沿箭头识别蒸发、大气输送、降水、径流、入渗与地下水流等通量，这些过程彼此连接，形成回路而不是一条单向路径。第三步追踪驱动力：太阳能驱动蒸发和大气输送，重力推动降水、径流与下渗。图中海洋覆盖地球表面约百分之七十一，这说明海洋是理解全球水循环时不可忽略的背景储库。

# 23_全球碳循环 Global Carbon Cycle

读碳循环图时，框表示储库，单位是吉吨碳；箭头表示通量，单位是吉吨碳每年。图中的一百二十和八十吉吨碳每年是高频总交换，不能直接当作净碳汇。生物过程和海气交换的通量较高、交换较快，而硅酸盐风化与火山返回都小于零点一吉吨碳每年，代表缓慢的地质通量。因此，大储库、快交换和净变化是三个不同问题，储库不等于通量。

---

# 27_海洋如何把碳送入深处 Ocean Carbon Pumps

大气二氧化碳进入表层海洋后，可以沿三条路径向深处转移。物理泵依靠低温提高溶解度，并随深水形成和环流把溶解无机碳带到深海；生物泵先由光合作用形成有机碳，再通过颗粒下沉和深处分解完成转移。碳酸盐路径把生物成壳、沉降与碳酸钙埋藏连接到沉积物和岩石。教材支持的背景事实是，深层水的无机碳浓度约比表层高百分之十五；关键仍是区分三条路径的机制与箭头方向。

# 35_什么是反馈 What Is Feedback

正反馈和负反馈描述的是作用方向，不是在评价结果好坏。判断时先明确初始变化，再跟踪它诱发的变化，最后比较诱发作用与初始方向。若两者同向，回路会放大或加强原变化，这是正反馈；若诱发作用反向，回路会抑制变化并使系统趋于稳定，这是负反馈。最可靠的判断方法始终是：找初始变化、跟踪诱发变化、比较最终作用方向。

---

# 38_岩石风化恒温器 The Weathering Thermostat

从大气二氧化碳增加或温度升高开始，更暖、更湿和雨水酸性更强的条件会加速硅酸盐风化。风化消耗二氧化碳，并增加进入海洋的钙离子等溶解产物，随后通过碳酸钙埋藏把碳转移到长期储库，使大气二氧化碳下降并产生冷却趋势。这个最终作用反对初始增温，因此构成缓慢的负反馈；响应时间大于十的五次方到十的七次方年。反向来看，冷却会减弱水汽和酸性、降低风化与二氧化碳去除，而火山输入可逐渐重建大气碳储库。这里必须限定为硅酸盐风化，不能把碳酸盐岩风化表述成同等的净大气二氧化碳汇。

---

# 44_核心知识点 Key Takeaways

最后把六条结论合在一起。第一，水和碳通过通量在储库之间迁移，储量不等于通量；第二，停留时间控制储库响应快慢，大储库不一定更新快。第三，水循环搬运物质和能量，并连接大气、海洋、岩石与生命；第四，碳循环同时包含快速的生物和海洋路径与缓慢的地质路径。第五，水通过风化、海气交换和生命过程把水循环与碳循环耦合起来；第六，正反馈放大变化，负反馈抑制变化，判断系统响应必须同时看方向和时间尺度。这六个关键词共同构成阅读地球系统循环的框架：储库、通量、停留时间、耦合、反馈和时间尺度。
